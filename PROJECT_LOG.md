# Media Tracker Project Log

## [v2.0.0-dev] - In Progress
### Planned / Current
- **Visual Overhaul**: Transitioning from text-based tables to a responsive gallery grid (MAL-style).
- **Architecture Refactor**: Moving to a professional subdirectory structure (`/html`, `/css`).
- **Database Expansion**: Migrating PostgreSQL schema to support `image_url` for visual posters.
- **Static Asset Serving**: Implementing absolute path resolution for cross-directory file serving.

## [v1.0.0] - February 1, 2026
### Finalized
- **Core Full-Stack**: Successful connection between Express/TypeScript backend and HTML/JS frontend.
- **Persistence**: Fully integrated PostgreSQL database with a verified schema.
- **CRUD API**: Robust endpoints for creating, reading, updating, and deleting media entries.
- **Validation**: Server-side logic to ensure data integrity for media types, ratings, and progress.

## [v0.1.0] - Initial Setup
### Completed
- **Backend Foundation**: Basic Express server with TypeScript and environment variable support.
